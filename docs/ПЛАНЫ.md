# Планы

1. **GPS:** приёмник видит спутники, позиции нет; проверить на открытом месте и сравнить с другим телефоном, затем искать причину.
2. **Сон:** ночной замер (цель 30–35 мА, как в mainline-портах), пробуждения dsme раз в минуту, сторож WPSS (`m52xq-wpss-guard` из других портов).
3. **Фото:** пурпурный оттенок в пересвете, лицо против света, шумоподавление и резкость.
4. Аппаратные видеокодеки (Venus): проверить воспроизведение и запись.
5. Мобильный интернет: проверить обычное соединение (сейчас проверены только страницы операторов).
6. VoLTE, отпечаток пальца.
