# Sailfish OS 5.2 на Samsung Galaxy M52 5G (m52xq): руководство (v1)

Неофициальный порт: родной Sailfish OS 5.2.0.22 (без libhybris и Android) на основном (mainline) ядре Linux 7.1.13,
графика через Mesa freedreno. Проверено на одном SM-M526BR. English: [MANUAL-EN.md](MANUAL-EN.md).

## Что работает и что нет

Работает: экран и GPU, тач, кнопки громкости, автоповорот и автояркость; Wi-Fi; Bluetooth; звонки, SMS и мобильный интернет
на двух SIM-картах (обе активны); мелодия, разговорный динамик и громкая связь; гашение экрана у уха; звук; фонарик; датчики
освещения, приближения и ускорения; камера (четыре объектива, фото 64 Мп, вспышка); сон с пробуждением по Wi-Fi; батарея и
зарядка; менеджер SIM-карт; меню перезагрузки; снимок экрана двумя кнопками громкости.

Пока нет: позиция GPS (см. README), VoLTE, отпечаток пальца. Не проверено: аппаратные видеокодеки.

## Что нужно

- Разблокированный загрузчик и TWRP для m52xq.
- Карта microSD с архивом `sailfishos-5.2-m52xq-mainline-v1.zip` (620 МБ).
- Резервные копии EFS, persist, modem, boot, vendor_boot и vbmeta. Если вы не умеете восстанавливать Samsung через Odin,
  не устанавливайте.
- На телефоне должен быть `vendor` прошивки на базе Samsung (сток, UN1CA или LineageOS): из него установщик берёт прошивку
  Bluetooth и конфиги датчиков.

## Установка (TWRP)

1. Wipe → Format Data → `yes`, затем Advanced Wipe → Data → Repair or Change File System → Change File System → **EXT4**.
   Раздел данных становится `/home`, он должен быть ext4.
2. Install → Select Storage → Micro SD card → архив → Swipe to confirm Flash.
3. Дождитесь `Updater process ended with RC=0` и нажмите Reboot System.

Установщик записывает boot, vendor_boot и dtbo, увеличивает `system` (lptools, до 8 ГБ, если есть место), до записи проверяет,
помещается ли образ, и записывает образ системы. Закрытые прошивки Samsung/Qualcomm в архив не входят: установщик копирует их
с разделов этого же телефона, только чтением.

Если на телефоне есть файл `/data/rootfs.img`, загрузится он, а не новая система (установщик об этом предупредит):
переименуйте или удалите его.

## Первый запуск

- Первая загрузка дольше обычной: создаётся пользователь, затем запускается мастер Sailfish (язык, лицензия, Wi-Fi).
- SSH по USB (`172.16.42.1`) или Wi-Fi: пользователь `root`, пароль `m52xq`. Смените пароль.

## Советы

- **Две SIM-карты:** приложение «Менеджер SIM-карт»: обе SIM / только SIM 1 / только SIM 2, SIM для мобильных данных,
  выключение SIM-карт и радио. SIM для звонков: Настройки → SIM-карты. При «всегда спрашивать» выбор SIM пропадает из
  шторки; выберите там SIM, и он вернётся.
- **Камера:** кружки 0.5 / 1.0 / M выбирают объектив, две стрелки — фронтальную. Коснитесь картинки, чтобы сфокусироваться
  (только основная камера). Вспышка в настройках камеры; светодиод загорается примерно за секунду до снимка.
- **Bluetooth:** с подключённой гарнитурой телефон не засыпает (иначе связь рвётся). Без подключённых устройств Bluetooth
  выключается при погашенном экране.
- **GPS:** включите онлайн-помощь (Настройки → Местоположение).
- **Снимок экрана:** одновременно громкость вверх и вниз.
- **Фонарик:** шторка. Если плитки нет: Настройки → Верхнее меню → Фонарик.
- **Перезагрузка в TWRP:** приложение «Меню перезагрузки».
